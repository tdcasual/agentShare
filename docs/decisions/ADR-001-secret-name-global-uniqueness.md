# ADR-001 Secret 名称全局唯一

日期：2026-07-20（追溯记录于 2026-08-20）
状态：已采纳

## 背景

Secret 名称需要唯一性约束。可选方案：按属主+空间范围唯一，或全局唯一。范围唯一更"工整"，但会让名称冲突探测、跨空间搜索与未来迁移复杂化。

## 决策

Secret 名称**全局唯一**（迁移 `20260720_01_unique_secret_and_token_names.py`；存量重名按"保留最早行、其余追加 ` (n)` 后缀"修复）。

## 后果

- 已接受的权衡：创建/改名失败能间接探测某名称**存在**（存在性旁路）。在单管理员自托管模型下，攻击者即管理员本人，该旁路不构成实际风险，故不做防御。
- 若未来引入多管理员/多租户，必须重新评估本决策。
- 2026-08-19 安全审计确认维持现状，不做代码变更。
