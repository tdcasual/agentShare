# ADR-002 改密不连带吊销管理/agent 令牌

日期：2026-07-13（追溯记录于 2026-08-20）
状态：已采纳

## 背景

修改管理员密码时，是否应连带吊销所有管理令牌（`vgm_`）与 agent 令牌（`vg_`）？

## 决策

改密**只吊销会话**（`vgs_`，改密成功即全部失效并清除 Cookie），不吊销 `vgm_`/`vg_`。令牌是独立签发的长期凭据，其生命周期由显式管理动作控制；应急场景由一键吊销端点补位：`POST /api/admin/security/revoke-all-tokens`（仅会话可调用，审计动作 `admin.credentials.revoke_all`，提交 4cd6c88）。

## 后果

- 自动化的令牌不因改密意外中断。
- 怀疑凭据泄露时的标准动作序列：改密（断会话）→ 一键吊销（断所有令牌）→ 按需重签。该序列写入 `docs/guides/production-security.md` 事件响应章节。
