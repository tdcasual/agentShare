# ADR-004 控制面 UI 为过渡版，重建中

日期：2026-08-20
状态：已采纳

## 背景

控制面前端经历过多次迭代，现行界面是过渡形态；完整的 shadcn/ui 重写在分支 `ui/shadcn-rebuild` 上进行（Phase 0/1 与 Phase 2 脚手架已完成，页面迁移待续）。

## 决策

- 新功能的前端按**现行模式**实现（参照 `src/app/settings/security`），不做过度视觉打磨；
- 不在旧 UI 上投入大规模重构；
- 视觉回归基线（见 ADR-005）以当前实现为准，重建合并后统一重录。

## 后果

- agent 与协作者避免在将被替换的界面上做精细工作。
- 重建合并时需要：整体重录截图基线、复核无障碍测试、更新本 ADR 状态为"已废弃/已完成"。
